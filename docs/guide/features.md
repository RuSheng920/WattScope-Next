# 功能详解

三个主 Tab：**仪表盘 / 记录 / 设置**。权限中心是设置内的二级页。

## 仪表盘

首页把「现在这一秒发生了什么」压在一屏里：

- **总功率大数字**：当前 SoC 总功耗（W），单位与基线对齐
- **状态胶囊**：记录中 / 预览中 / 权限就绪
- **实时分区柱状图**：SOC → CPU-L（大核）→ CPU-M（小核）→ GPU → NSP，每根柱子带数值标签、峰值标注与**功耗占比**，柱子自基线向上生长
- **附加指标**：CPU 簇频率、每核占用（按簇着色、纵轴每 10% 分度）、GPU 频率与占用、DDR 频率、四路温度、整机功耗

预览循环在界面可见时按采样间隔刷新；**界面不可见时降为 1 Hz**，曲线不断点，也不让息屏后的高频采样白白烧电。

分区的展示顺序在全应用内是统一的：首页、详情页、OSD 与平均功耗卡完全一致，跨页面看数据不用重新适应。

## 记录

「记录」Tab 是历史列表：

- 每条记录显示应用图标、应用名、时间范围、时长与平均功耗
- 点进详情页看完整曲线
- 空状态是图标 + 标题 + 说明，而不是一片白

### 详情页

详情页是这套工具真正的阅读界面：

| 能力 | 说明 |
| --- | --- |
| 平均功耗置顶 | 打开就能看到这段记录的整体水平 |
| 全局同步十字光标 | 在一张图上移动，所有图的同一时刻一起高亮 |
| 浮动 Tooltip | 显示该时刻各指标的精确数值 |
| 每图独立平均值 | 每张图有自己的横向均值线，不混用全局值 |
| 分区筛选 | 只看某个分区或某个核簇 |
| 曲线排序 | 九个区块各自 ↑ / ↓ 调序，全局持久化 |
| 导出 | JSON（完整字段）/ CSV（表格分析） |

默认曲线顺序按分析动线排列：**总功率 → 性能结果 → 原因下钻 → 分区细分 → 温度收尾**。这个顺序不是随意定的——先看结论，再看为什么。

::: tip 大记录也不卡
详情页用 stride 降采样 + 后台线程聚合，录制中打开历史也不会把数据库打满。相比 1.0 的「订阅整张表」，长记录打开速度差别很明显。
:::

## 设置

设置首页是**分类索引**：每一类设置点进去是独立页面，一屏可见全部入口，不用在一条长列表里找东西。

| 入口 | 里面有什么 |
| --- | --- |
| 外观与主题 | 主题模式、语言、液态玻璃 |
| 采样与功耗 | QPT 总开关、采样间隔、双电芯补偿 |
| 悬浮窗与 OSD | 悬浮球大小与边缘吸附、OSD 开关与显示项 |
| FPS 数据源 | 自动跟随前台应用；也可从扫描结果里挑图层，列表直接显示每层的实测帧率 |
| 服务与权限 | 权限中心、重启前台服务、电池白名单、自启动 |
| 关于 | 版本号与项目主页 |

二级页顶栏带返回箭头，系统返回手势也支持（跟手缩放 + 圆角，MIUIX 预测性返回）。

### 采样与功耗

- **采样间隔**：默认 200 ms（5 Hz），可自行调整
- **双电芯机型**：部分双电芯机型的电池驱动只上报单路电芯电流，整机功耗会低估约一半。开启后按两路求和，实时预览、OSD 与落库同步生效（在「校准」分组下）
- 所有监控项与 SoC 功率**同采样率**落库，详情页各图时间轴逐点对齐

### 外观与主题

深色 / 浅色 / 跟随系统三态，偏好本地持久化。

底栏是 MIUIX `FloatingNavigationBar` + Backdrop 实现的**悬浮液态玻璃**：实时模糊、边缘折射、内阴影，浓度三档可调，也可以回落为贴底样式。底栏开关、浓度与记录期降级都收在本页的「液态玻璃」分组里。

::: warning 记录时降静态玻璃
「记录时暂停实时模糊」默认开启。逐帧模糊会持续占用 GPU，污染你正在测的功耗数据——所以记录态只保留静态玻璃底衬。
:::

### 悬浮球与 OSD

详见[悬浮球与 OSD](/guide/overlay)。

### 语言

界面提供简体中文与英文：默认跟随系统，也可以在「设置 → 外观与主题 → 语言」固定为其中一种（Android 13+ 系统级 per-app language）。切换后界面立即重建，采样服务与正在进行的记录都不受影响。

### 服务与权限

权限中心是逐项的授权状态清单，入口显示当前的「就绪」状态胶囊；重启前台服务、电池优化白名单与 MIUI 自启动放在同一页的「服务与保活」分组。
